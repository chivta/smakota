# Nutrition data sources: gas-station food, bakeries, meal-prep delivery, frozen meals, ice cream

Track scope: everything eaten out of home in Ukraine that is neither a classic restaurant nor a supermarket. Verified live on 2026-09-13 with `curl -sL -A "Mozilla/5.0"` and web search (Ukrainian/Russian/English). A prior attempt at this track was cut off mid-run (`03-fuel-bakeries-meals.log`); its leads (rud.ua, 3bears.ua, kyivkhlib.ua, lvivcroissants.com, e2go.com.ua, racion.com.ua, proe.info, easyeat/eater/5blyud, galyabaluvanakyiv.com.ua) were re-checked directly rather than trusted as-is; several of its findings (proe.info scale, 3bears/kyivkhlib item counts) held up, one (galyabaluvanakyiv.com.ua) turned out to be a dead subdomain for a brand whose real site is elsewhere.

## Notes

**SOCAR Buta Cafe** renders as an empty shell via curl — the ordering interface (socar.ua/cafe/<station id>) is a client-side app; any nutrition data it might carry is loaded by JavaScript after page load and is invisible to a plain HTTP fetch. The `ua.pricelisto.com/menu-prices/socar-buta-cafe-ua` third-party aggregator has prices but no per-item kcal in the HTML fetched.

**Лімо/Хрещатик (limo.ua)** is fully blocked by a Cloudflare managed challenge on every path except `robots.txt`. That robots.txt is notable on its own: it publishes an explicit AI/content-signal policy (`ai-train=no`) and hard-disallows a named list of AI crawlers (GPTBot, ClaudeBot, CCBot, Google-Extended, Bytespider, Amazonbot, Applebot-Extended, meta-externalagent). Any scraping plan for this brand needs a headless browser or third-party mirrors (tablycjakalorijnosti.com.ua), not curl.

**Рудь (rud.ua)** currently serves a static "site under reconstruction" page — it is a live but temporarily empty domain, not a permanently dead one. Re-check periodically.

**Мама Манана** is a Next.js single-page app: the static HTML only contains i18n label strings ("kcal", "Carbohydrates") with the actual numeric values fetched client-side, so per-dish macros could not be confirmed by curl even though a live web-search snippet quoted a full breakdown for one khachapuri (602 kcal, 12.8 g protein, 43.6 g fat, 51.9 g carbs). Getting real data from this source would need either a headless browser or reverse-engineering its API calls.

**UPG, Milk Bar, and the Lviv Chocolate café location** all run their online ordering on the same third-party platform, ChoiceQR (`<subdomain>.choiceqr.com`), which embeds menu data as JSON directly in the page HTML (`"kcal":<number>`) — this only carries kcal, never protein/fat/carbs. Any other Ukrainian food business using ChoiceQR for delivery/pickup ordering is likely to expose the same `kcal`-only field for free via a plain HTTP GET, no auth needed. Worth checking for other chains not in this track.

**proe.info** is the largest single open source found in this track (and possibly across the whole research effort): ~10,092 Ukrainian-language product pages, each carrying full per-serving Б/Ж/В/ккал plus ingredient text and a barcode. It appears to be a general packaged-goods database (its title references "E-additives"), so it overlaps heavily with supermarket own-brand and manufacturer products too, not just this track's brands.

**tablycjakalorijnosti.com.ua** functions as a catch-all secondary/tertiary source for brands whose own sites don't expose nutrition (Кулиничі, WOG Cafe, Хрещатик, Лімо, Ласунка, Геркулес, Галя Балувана SKUs). Its terms of use explicitly forbid copying or reusing its data, which matters if any of this ends up feeding a bot's food database rather than one-off manual lookups.

**Vending machines** are a distribution channel, not a nutrition data source: the products sold (Snickers, Lay's, canned drinks, biscuits) are standard packaged branded goods already covered by proe.info and manufacturer/retailer catalogues in other tracks. No vending-specific nutrition source exists.

**Кулиничі (Kulinichi)** self-reports "400+ SKUs, 60% developed in-house" on its corporate site, but this is an unverified company claim, not a counted catalogue — flagged as such rather than presented as fact.

## Dead ends

- **FitBox (fitbox.kiev.ua)** — domain did not resolve/connect via curl (connection failure on both http and https); cannot verify it is still operating.
- **hercules.ua (Геркулес)** — domain did not respond (connection failed) during this check; real company confirmed via secondary sources (liga.net company profile) but the site itself is currently unreachable.
- **galyabaluvanakyiv.com.ua** — returned an empty (0-byte) response; this looked like a franchisee city subdomain, but the brand's real official site is `galia-baluvana.com`, which does work.
- **Bon Boutique** — could not confirm this as a real, named bakery/confectionery chain in Ukraine; no matching official site or independent listing found. Dropped as likely invented or misremembered.
- **Пан Пекарь** — only found as an unrelated Russian home-bakery brand (Chelyabinsk) and a few unverified TikTok mentions of a Sumy business; no confirmed Ukrainian chain with an official site. Dropped.
- **Ласунка** — no official manufacturer website found (only retail listings and third-party calorie sites); brand itself is real and well documented elsewhere.
- **WOG Cafe (wog.ua)** — no dedicated menu/nutrition page found on the official site; only news posts about seasonal menu changes.
- **BRSM-Nafta, Shell/Авіас, Motto** — all confirmed real gas-station chains with cafés, but no nutrition information found on any of their official sites.
- **Kulinichi corporate + shop sites** — no nutrition data on either kulinichi.com or kulinichi.shop; would need to check individual retailer listings (covered in the supermarket track) instead.
- **SOCAR Buta Cafe** — JS-rendered SPA; no nutrition data retrievable without a headless browser.
- **Lviv Croissants (lvivcroissants.com)** — public menu page has ~101 items and zero calorie mentions; nutrition, if it exists, is not published on the site.
