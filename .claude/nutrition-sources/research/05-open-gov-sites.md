## Notes

**Open Food Facts** — this is the strongest single source in this track for the user's actual diary: it directly returned Ukraine-tagged entries for Яготинське dairy products and Non Stop Jungle, and international entries for Snickers, Lay's, KitKat, Sandora. The `countries_tags_en=Ukraine` filter (7,286 products) undercounts real UA-market coverage since many barcodes aren't tagged with a country. `energy-kcal_100g` (with a hyphen, not underscore) is the correct nutrient field name — an early query in the prior run's log used `energy_kcal_100g` and silently returned `null` for it.

**USDA FDC** — the DEMO_KEY works fine for light querying (a handful of requests/minute) but is rate-limited; a free registered key removes that limit. FNDDS/Branded results skew toward US products/dish-naming conventions (e.g. "borscht" hits are US grocery-brand soups, not a generic recipe entry), so it's more useful as a macro-estimate fallback for internationally branded items (Snickers, KitKat) than for Ukrainian home-cooked dishes.

**German BLS** — access could not be fully verified from this shell: the `blsdb.de/download` page did not expose a direct file link to curl (likely JS-rendered or gated behind a request form), and multiple German news outlets report the licence fee was dropped only recently (late 2025), so older documentation describing a €100+VAT single-seat fee may be stale. Treat "now free" as probable but not independently confirmed against the primary source.

**Fineli** — fineli.fi returns a Cloudflare "Just a moment..." challenge page to plain curl even with a browser User-Agent, so the documented open JSON API could not be exercised directly; relied on THL's own open-data documentation page instead.

**Canadian Nutrient File** — the bulk CSV on open.canada.ca returned an explicit WAF "Request Rejected" page rather than the file; the interactive search tool at food-nutrition.canada.ca was not exercised in this pass, so no diary spot check was possible.

**Calorizator.ru, Health-diet.ru, Dietolog-type .ru sites** — these Russian-hosted domains resolved via DNS from this shell (confirmed with `getent hosts`, real IPs returned) but every `curl` connection attempt timed out (exit code 28) rather than returning any HTTP response, including via alternate hostnames. This looks like a network-level block on this shell's egress (likely to Russian IP ranges) rather than a site-side block, since even the TCP connection never completed. WebSearch snippets confirm these are real, longstanding calorie-table sites, but no live spot check against `products.txt` was possible.

**Ukrainian official (МОЗ) tables** — no live, browsable per-product database was found. The only concrete official artifact located is a 2000-era methodology document (zakon.rada.gov.ua/go/z0146-00) describing how to *calculate* composition/energy value, which was itself noted as having lost legal force in 2014; the currently-in-force reference is a 1999 set of physiological-needs norms, described by secondary sources as outdated and not a food-item table at all. This is functionally a dead end for a calorie bot (see Dead ends).

**Skurikhin (Soviet/Russian reference)** — no official digital release exists; only scans on Internet Archive and file-sharing/pirate sites (Scribd, Eruditor, studmed.ru) were found, several carrying an explicit "no reproduction without permission" notice from the original publisher. Given the ongoing war, sourcing core bot data from a Russian state-era publication (and via scan-sharing sites of unclear legality) is both a licensing and an optics problem; usable at most as a manual cross-reference for generic Soviet/Eastern-European dish composition (борщ, окрошка), never as a bulk import.

**Tablycjakalorijnosti.com.ua** — despite the Ukrainian domain and name, the sitemap sample (`wheat-tortilla-metro-chef`, `manuka-honey-10-marksspencer`, `merlot-alcohol-free-freetime`) suggests this is a generic, likely OFF-derived or scraped, multilingual product mirror rather than a Ukraine-curated table; a direct site search for "Snickers" returned a 404. Its ~590,000-URL foodstuff sitemap is a real size signal but the content mix looks international, not UA-specific.

**EuroFIR FoodEXplorer** — paywalled (pay-per-view or AISBL membership); not accessed. Useful only as a meta-index of which national databases exist, most of which are separately listed in this table.

**EFSA food composition database** — the current (2013-vintage) version only covers 7 EU countries and is not the open pan-European database; EFSA's own pages state a genuinely open-access EU-wide food composition database (EU FCDB) is planned for publication "mid-2026" and was not available to check at research time.

## Dead ends

- **ДУ «Інститут громадського здоров'я» / colloquial "МОЗ tables"** — no live, structured, per-product nutrient database found; only a superseded 2000 methodology document and outdated 1999 physiological-needs norms turned up.
- **ДСТУ (Ukrainian state standards)** — no evidence found of a ДСТУ standard that publishes a browsable food composition table (ДСТУ standards define product specs/quality grades, not КБЖУ tables); not pursued further given no concrete lead surfaced.
- **ЄДА?** — could not locate an independent product/nutrition database tied to this brand; appears to be a media/TV property, not a data source.
- **Fineli (fineli.fi)** — Cloudflare challenge blocks scripted access from this shell; the documented open API and CC BY 4.0 licence could not be exercised directly (see Notes).
- **Calorizator.ru, health-diet.ru, other .ru calorie sites** — reachable by DNS but every connection timed out from this shell's network (see Notes); could not spot-check content.
- **Canadian Nutrient File bulk CSV (open.canada.ca)** — WAF rejected the direct file download; only the dataset's existence and stated size (5,690 foods) were confirmed via search.
- **German BLS direct download** — `blsdb.de/download` exposed no direct file link to curl; access details assembled entirely from secondary press coverage.
- **Skurikhin official digital edition** — no legitimate official download exists; only scans of uncertain provenance/legality.
