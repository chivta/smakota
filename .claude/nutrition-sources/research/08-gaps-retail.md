## Notes

1. **Фора / Fozzy RPC API.** No documented public REST/GraphQL surface exists, but GitHub has multiple independent scrapers targeting the same `.../api/2.0/exec/<ServiceName>` pattern across the whole Fozzy Group backend family (Фора, Сільпо-adjacent projects): `CloCkWeRX/alltheprices` (`products/spiders/fora_ua.py`), `Dankoss-Organization/parser-for-shop-comparison-platform` (`scrapers/fora/api_client.py`), `volkovn1kita/GroceryScanner` (`ForaService.cs`), `madinaadzhi/aggregator` (`ForaMarketApi.java`), plus sibling Silpo clients on the same platform (`gebeto/info`, `mcharniuk1-spec/silpo1`/`silpo2`, `DenysDiakonov/gre4ka`). The confirmed call shape is a POST of `{"method": "GetSimpleCatalogItems" | "GetDetailedCatalogItem", "data": {...}}` to `EcomCatalogGlobal` — JSON-RPC-style, not REST. `GetDetailedCatalogItem` on the shared platform schema does define a nutrition field (`nutritionalValue`, per the `doubledare704/silpo-py-mcp` typed client), but no snippet or scraped sample in this pass showed it actually populated for a fora.ua product, and Google snippets for `site:fora.ua калорійність` returned no nutrition numbers. Net: technically reachable if you replicate the exact JSON-RPC call, but unconfirmed whether Фора's own SKUs carry nutrition data through that channel.
2. **АТБ.** Still fully Cloudflare-blocked to curl/WebFetch, but this pass found stronger evidence than track 01 that nutrition text does exist: Google search snippets for `site:atbmarket.com калорійність КБЖУ` return real numeric values directly in the snippet (eggs, chicken wings, baby cereal, bread), meaning the field is present and indexed even though it can't be fetched directly. GitHub scrapers (`truenormis/atb-api`, `alikkosenko/goods_parser`, `adv4nt4ge/grocery_scraper`) confirm a `GET /api/v1/products` REST endpoint exists on atbmarket.com. Total catalogue size remains unknown — no press release or app-store figure was found.
3. **Сільпо MCP / AI Factory.** Confirmed hackathon-only, not general-access: registration closed 2026-09-01, the hackathon's dev/submission/finals window runs through 2026-09-30, and the docs explicitly call MCP integration "обов'язкова частина кожного проєкту" (a mandatory hackathon deliverable, not a public product). A third-party GitHub client (`doubledare704/silpo-py-mcp`) built for this hackathon ships a mock server specifically because a real Silpo account plus hackathon enrollment is required to hit the live endpoint.
4. **Varus.** The `robots.txt`-listed sitemap path (`varus.ua/sitemap-index.xml`) is stale and 404s; the real sitemap lives at `varus.ua/media/sitemap/sitemap.xml` and totals 81,437 URLs across 2 shards, mixing food, non-food and category/brand pages. Nutrition is confirmed present and machine-parseable (an embedded `attribute_code`-keyed JSON blob) on all 3 spot-checked food products (a cocoa drink, a weighed cheese, a cake).
5. **supermarkets.com.ua.** Confirmed this pass to be a promotional-price aggregator pulling from 6 named chains (MAUDAU, АТБ, Сільпо, Варус, METRO, Auchan), not an independent retailer — its own product pages nonetheless carry real schema.org nutrition microdata, confirmed on 2 diary-adjacent products.
6. **proe.info.** Identified this pass as a sister project of Dobavkam.net (a long-running Russian/Ukrainian food-additive/E-number reference site), not an independent company — no WHOIS registrant, "about us," or app-store listing exists beyond that. No terms-of-use page exists at all (`/uk/terms` and `/uk/pro-nas` both 404, no ToS link anywhere in the nav). Coverage is uneven: it has Яготинське and Sandora SKUs but nothing for Non Stop or Галя Балувана, consistent with it being a general packaged-goods/barcode database rather than a curated Ukrainian retail-brand index.
7. **tablycjakalorijnosti.com.ua.** The two earlier passes' disagreement is resolved: both were right about different things. It genuinely is the Ukrainian instance of a large international network — specifically **Dine4fit, a.s.** (Czech company, IČO 25766937, Hradec Králové), the same operator as kaloricketabulky.cz (cross-confirmed via the Google Play listing for "Таблиця калорійності", package `cz.psc.android.kaloricketabulky`) — and its foodstuff sitemap really does total ~589,526 pooled international URLs, so the "generic mirror" framing is accurate at the whole-database level. But within that pool, real Ukrainian-brand coverage is substantial (Своя Лінія 1,159 pages, Галя Балувана 779, Власна Випічка 333, Ласунка 248, Кулиничі 245, Favore 162, Хрещатик 66, WOG 16), so the "has real UA brand pages" framing is also accurate at the item level. Data is a mix of pack-label/third-party-sourced base data plus user-submitted photos/recipes (licensed to Dine4fit for 24 months, renewing, including for ML training, per its terms page). 4 of the 5 named diary items were found directly; the Фора bacon muffin was not.
8. **Other sources.** calorize.com.ua turned out to be a Ukrainian AI calorie-tracker app's public product-page layer, not a static calorie table — no sitemap or stated size exists, so its scale is genuinely unknown. No government food-composition dataset exists on data.gov.ua: searching `q=харчова цінність` returns "Не знайдено жодного набору даних" (no dataset found) explicitly, and the only hits for `q=калорійність` are agricultural production-balance statistics (e.g. "Баланси основних продуктів рослинництва та тваринництва"), not per-food nutrition tables. The "ЩоЇм" barcode app could not be investigated in this pass: the session's WebSearch budget was fully exhausted (200/200) before this question could be researched, and a direct Google Play search via curl was blocked by Google's bot-redirect page — this remains an open gap for a follow-up pass with a fresh search budget. Of the four small chains: **Наш Край** (shop.nashkraj.ua) and **Копійочка** (kopiyochka.ua) both have real online food catalogues with confirmed nutrition fields on spot-checked products; **Рукавичка** has an online shop (market.rukavychka.ua) but the one product page checked (a Torchin sauce) showed only price/delivery info, no ingredients or nutrition at all; **Близенько** (blyzenko.ua) is a WordPress marketing site with a store locator only — no online catalogue exists to check.

## Dead ends

- **Рукавичка product page checked (market.rukavychka.ua, Torchin sauce)** — page has price, delivery/payment info and buy button only; no ingredients or nutrition section present on this SKU.
- **data.gov.ua** — no food-composition/nutrition dataset exists; only agricultural production-balance statistics surface for nutrition-adjacent search terms.
- **Google Play / ЩоЇм app lookup** — blocked in this pass by exhausted WebSearch budget and Google's bot-detection redirect on direct curl requests; unresolved, not confirmed dead.
- **calorize.com.ua sitemap** — `/sitemap.xml`, `/sitemap_index.xml`, `/sitemap/sitemap.xml` all 404; no crawlable size signal for this source exists.
